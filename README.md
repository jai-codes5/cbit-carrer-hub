 CBIT CAREER PORTAL - STUDENT DRIVE TRACKER

A Full-Stack Campus Placement & Internship Management Portal built using **Python FastAPI** and **SQLite**, specifically tailored for tracking real-time campus drives at CBIT.

Features
- **Real-time Live Feed:** Immediate updates of new companies on the portal without page refreshes.
- **Placement & Internship Log:** Track company name, role, CTC, required skill-set, and active status.
- **Lightweight DB Storage:** Powered by SQLite with structured data schemas for persistence.
- **CORS Enabled:** Fully secure, cross-origin communication between backend APIs and native UI.

 Tech Stack
- **Backend:** Python, FastAPI, Uvicorn, Pydantic
- **Database:** SQLite3 (Relational DB)
- **Frontend:** Responsive HTML5, Native CSS Grid layouts, JavaScript Fetch APIs
